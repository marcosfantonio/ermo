# ERMO

> **Há lugares dos quais nunca saímos.**

Uma estrada de terra corta morros verdes. Casas com alpendre aparecem pelo caminho; ao longe, postes e turbinas se perdem na névoa. A paisagem é quieta, quase acolhedora — e familiar de um jeito difícil de explicar.

**ERMO** é um jogo de exploração e estranheza inspirado em lugares cotidianos do Brasil. O desconforto vem de reconhecer uma casa que não deveria estar ali, de seguir uma estrada que parece voltar ao mesmo lugar, de perceber que alguma coisa mudou enquanto você não olhava.

## O que fazer

Observe o lugar. Explore as casas e os caminhos. Preste atenção ao que parece fora do lugar e descubra se existe uma passagem para outro canto desse mundo. A história não entrega todas as respostas: as pistas e as contradições fazem parte do mistério.

**No protótipo atual**, você pode caminhar livremente pelos Sítios, explorar as casas e encontrar caixas-d'água que escondem uma passagem para um **balneário procedural contínuo**. Do outro lado, você emerge dentro de uma piscina e o parque aquático continua sendo gerado conforme você explora, sem cercamento externo. Ainda não há missões, combate, inventário ou final — por enquanto, o objetivo é explorar e descobrir o que o lugar guarda.

## Controles

| Tecla | Ação |
| --- | --- |
| **W A S D** | Andar |
| **Shift esquerdo** | Correr |
| **Espaço** | Pular |
| **Mouse** | Olhar ao redor |
| **E** | Interagir com portas, janelas e escadas quando aparecer o aviso |
| **Esc** ou **F1** | Abrir opções |
| **H** | Mostrar ou ocultar as dicas |

Nas escadas das caixas-d'água, use **W/S** para subir ou descer. **E** solta da escada; **Espaço** também permite sair pulando.
